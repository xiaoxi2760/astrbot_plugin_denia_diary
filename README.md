# 🌸 情绪日记

日记和主动消息插件。让 bot 有自己的日子：写日记、记小本本、有心情和作息，也会主动找你说句话。

- **一本日记**：想写就写，一天可以写好几段；她自己翻、自己改、自己删，但开头那行（什么时候、什么心情写的）不会变，改删前还会自动备份一份。
- **两本**：普通日记给所有人；「恋爱日记」只写给你指定的人，也只有那个人能看到。
- **小本本**：只记两类——答应过的事（可以带期限）、对方说过的重要的事。日常闲聊、情绪、玩笑不记。
- **心情和作息**：心情由她自己说，系统不猜；作息表配好后，她知道自己这个点"刚醒"还是"该睡了"。
- **熟悉度**：按互动慢慢涨，太久不聊会慢慢降。只是给她自己参考的档位词，不会拿数字打扰你。
- **主动消息**：早上问好、晚上道晚安、提醒你答应过的事、你很久没来、她心情实在不好……各有各的时机和频率上限。
- **观察面板**：总览 / 日记 / 小本本 / 熟悉度 / 曲线与主动 / 数据 / 设置，七个页面。
- **心情暗号**：她实在撑不住的时候，会发一个字符给你（默认「。」）。只发这一个字，不带任何解释。

**数据都是能直接打开的文件**——日记就是两个纯文本，用记事本就能看，不锁在数据库里。

## 第一次用

装好后到 **Dashboard → 插件管理 → 情绪日记 → 插件页** 打开面板就行，其余都能在面板里改，不用下指令。
默认只在私聊工作；首页那块「这里可以放图」是封面图位，点右边的「选择文件」传一张自己的图。

面板「设置」页里能单独关掉任何一块，也能改标题、作息表、主动消息频率。
