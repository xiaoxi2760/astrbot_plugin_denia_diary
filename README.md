# 🌸 情绪日记

日记和主动消息插件。让 bot 有自己的日子：写日记、记小本本、有心情和作息，也会主动找你说句话。

## 功能

- **一本日记**：想写就写，一天可以写好几段；她自己翻、自己改、自己删，但开头那行（什么时候、什么心情写的）不会变，改删前还会自动备份一份。
- **两本**：普通日记和恋爱日记都按人归属；「恋爱日记」只写给你指定的人，也只有那个人能看到。
- **续聊线索**：私聊时带上最近写过的经历和与当前话题相关的日记片段，包括当天的新进展，方便接着之前的事聊。
- **小本本**：只记两类——答应过的事（可以带期限）、对方说过的重要的事。日常闲聊、情绪、玩笑不记。
- **心情和作息**：心情由她自己说，系统不猜；作息表配好后，她知道自己这个点"刚醒"还是"该睡了"。
- **今天的生活**：每天自己安排少量活动，知道当前在做什么、接下来去哪；安排落盘，重启后接着走。当前活动和确认过的结果会成为聊天素材。
- **熟悉度**：按互动慢慢涨，太久不聊会慢慢降。只是给她自己参考的档位词，不会拿数字打扰你。
- **主动消息**：早上问好、晚上道晚安、提醒你答应过的事、你很久没来、她心情实在不好……各有各的时机和频率上限。
- **观察面板**：总览 / 今天 / 日记 / 小本本 / 熟悉度 / 曲线与主动 / 数据 / 设置。日记页可以**改、删**，删掉的段落进**回收站**、能一键还原。
- **日记留言**：展开某段日记下的「留言」保存草稿，再点「让她知道」。她会在下一次与你的私聊或主动消息中看到一次；草稿不会交给她，待交付的留言可以撤回。
- **曲线与巡检**：当下心情和近期基调分开画，点日期能翻那天的日记；主动消息页也会说明最近一次为什么没发、是否发送成功。
- **心情暗号**：她实在撑不住的时候，会发一个字符给你（默认「。」）。只发这一个字，不带任何解释。**可以在「设置 → 主动消息 → 心情暗号」里关掉**，关掉后她再也不会发这个字符（字符本身和冷却天数也在同一处改）。
- **早晚安**：你对她说早安、晚安，她会记着你的作息——几点睡、几点起、连着多少天。这些她自己知道，聊天里会提到，问她一句也能翻到记录；你先说了晚安，她当晚就不再重复道晚安。

**数据都是能直接打开的文件**，不锁在数据库里——日记一行一段 JSON（`日记.jsonl`），文本编辑器就能看；旧版的 `日记.txt` 会自动导入一份，原样留在数据目录里当可读的旧档。

## 安装

需要 AstrBot **4.24.2 及以上**，更旧的版本装不上（宿主会拒绝加载）。

- **从仓库安装**：管理面板「插件管理」里填仓库地址 `https://github.com/xiaoxi2760/astrbot_plugin_denia_diary`；
- **手动安装**：把 `astrbot_plugin_denia_diary` 整个目录放进 AstrBot 的 `data/plugins/`，在「插件管理」里启用。

目前只在 QQ（NapCat / aiocqhttp）真机验证过；其余平台没测过，不打包票。

## 使用

装好后到 **Dashboard → 插件管理 → 情绪日记 → 插件页** 打开面板就行，配置都在面板里改，不用动文件。

两个指令：**/看日记**（别名 /日记卡）把一天写成一张日记卡片发到聊天里，`/日记款式`（别名 /日记卡样式）换卡片款式。

`/看日记` 是今天，`/看日记 10-06` 是那天，`/看日记 2026-10-06` 也行。卡片款式在面板「设置 → 内容 → 日记卡款式」里下拉选（六款：**纸感**（默认）/ 墨信 / 明信片 / **手帐** / 点阵本 / 火漆信笺），也可以直接在聊天里敲 **`/日记款式 手帐`** 换（中文别名认得，不用打英文）。还能在设置里**自定义卡片字体**（填字体名如 `Noto Serif SC`，或字体文件直链如 `https://…/xxx.woff2`）；渲染方式默认「精美」，可改为「朴素」（本地渲染，不出机器）或「只发文本」。

### 出图引擎（`设置 → 内容 → 日记卡出图引擎`）

「精美」那一档把卡片变成图片，可以选三条路：

| 选项 | 怎么出 | 大概多快 | 说明 |
| :--- | :--- | :--- | :--- |
| `auto`（默认） | 按下面顺序挑第一个能用的 | —— | 不想操心就留这个 |
| `playwright` | 本机 Chrome / Edge 截图 | 约 1.6 秒（首次），之后约 0.5 秒 | 排版最贴模板 |
| `remote` | AstrBot 官方文转图服务 | 约 4~11 秒 | **日记正文会发往该服务**；六款样式都能选 |
| `pil` | Pillow 直接画 | 约 0.3~0.5 秒 | 完全离线、不出网、不起浏览器；**只画纸感那一款**（不认款式设置） |

几点实际的：

- **默认很快，是因为有缓存**。同一天同一张卡只真正出一次图，之后再 `/看日记` 是毫秒级。改了日记、改了 CSS、换款式、日期变一天，都会自动重新出图。
- **默认禁止把日记正文上传到远端出图服务**，本机出不了图就发文本。选了 `remote` 也要在设置里打开「允许远端出图」才会上传。
- 本机要跑 `playwright` 或 `pil`，得分别装了 **playwright** / **Pillow** 和一张**中文字体**（Windows 的微软雅黑、macOS 的苹方、Linux 的 Noto CJK 都行）。缺了就自动退到下一条路。自动探测不准时可以设环境变量 `DIARY_CARD_BROWSER` / `DIARY_CARD_FONT` 手工指定。
- 打开「允许远端出图」后，`auto`、其他引擎的降级和精美卡片的文字转图兜底都可能使用远端；关闭后这些路径都不会上传日记正文。「朴素」始终在本机出图。

默认只在私聊工作；首页那块「这里可以放图」是封面图位，点右边的「选择文件」传一张自己的图。

日记、小本本、心情这些都是给她的工具，聊天里直接说就行：「把今天的事写进日记」「记一下，我答应你周日还书」——她自己会调。

面板里也能直接改日记：日记页每段下面有「编辑 / 删除」。删除先进回收站（上限 200 条），点「还原」会插回它原本的时间位置。

两本日记在页面顶部直接切换。主人首次优先打开有内容的恋爱日记，之后记住你选的本子、日期和阅读位置；切去别页再回来也能接着看。未保存的编辑和留言文字在本次面板会话里保留，换人时各自分开。

日记页有两个看法：**正文**是翻日记，**卡片**是看 `/看日记` 发出去那张图长什么样——按天翻页，右边有「第 N / 共 M 页」。卡片下面那排按钮可以挨个款式预览（**只改预览不动配置**），真要生效去设置里选，或敲 `/日记款式 手帐`。

默认面板和她同一条规矩——**只能改最近 7 天的**（设置里的「可改天数」）。想在面板里改任意一段，去「设置 → 内容 → 面板不受可改天数限制」打开它；这只放宽面板，她在聊天里仍然守 7 天。

改日记只改正文，**开头那行日期和心情永远不动**（那是历史）。改之前原文会自动备份到 `diary-trash/`。

## 配置

### 让她安排今天

插件启用后，生活任务独立运行：启动时检查今天有没有安排，此后每分钟检查一次。成功生成过就沿用原计划，不会每次聊天、打开面板或重启都重新请求模型。日程使用插件时区，与主动消息开关、联系人和发言配额分开；规划本身不会发送 QQ 消息。

打开 **今天** 看当前活动、下一项和整日时间线，直接编辑未来安排或填写活动结果。已经开始的安排保留；「时段已过」只表示时间到了，「已确认」才表示记录过结果。它们描述角色的虚拟日常，不代表执行过现实操作或完成给别人的承诺。

**设置 → 生活** 可以填公开生活偏好，留空时参考宿主默认人设；模型默认使用宿主当前文本提供商，也可填写已有提供商 ID。默认超时 30 秒、失败后隔 30 分钟再试，每天最多尝试 3 次（包含失败和手动重试）。失败保留原计划，没有计划时沿用静态作息；页面会显示原因。关闭生活开关保留数据。

日程是全局公开的角色生活，群聊也可能提到，不要把主人私事放进这里。面板可以调整，聊天里的修改和结果确认只允许最亲密名单里的主人私聊。可直接让她「看看今天安排了什么」「把之后的散步改成读书」「记下这次读书的感想」。私聊日记和恋爱本仍按原有可见范围保护。

### 画一下现在的她

面板的 **生图** 页可以按需画她当前的公开日常。实际调用默认关闭；先在 **设置 → 生活 → 状态生图** 选提供方、服务地址、模型与每日上限，再开启。打开或刷新页面只查看结果，不请求模型。图像提示词使用当前活动、地点、公开心情与人物／画风描述，不读取私聊日记或恋爱本。

本地支持 A1111 的 txt2img／img2img API；服务需要启用 API，参考立绘取自插件已有立绘仓库。云端支持 OpenAI 兼容 Images generations 的内联 `b64_json` 响应；这个适配器不传参考图或 seed。参考图参与生成也不保证人物完全一致，具体画面需要用选定模型验收。`model` 对 A1111 是 checkpoint 名称，留空使用服务当前模型；云端需要填写模型名。尺寸要符合该模型支持的规格。

密钥只通过环境变量提供：在宿主启动环境设置密钥，面板仅填写变量名（例如 `DENIA_IMAGE_API_KEY`），不要粘贴密钥本身。手机 Ubuntu 里的 `127.0.0.1` 指手机；电脑上的本地生图服务需填写手机实际可访问的地址。

每日次数在请求发出前持久记账；已开始的请求即使超时或失败也不返还次数。缓存命中不请求模型；A1111 未绑定 checkpoint 时无法确认服务是否换过模型，因此每次点击重新请求，填写模型名称后才复用同参数缓存。失败保留上一张成功图片；本轮加入 Pillow 图片校验依赖，依赖未就绪时拒绝发出生成请求。

### 群里参与和登记 bot

在 **群社交** 页登记群，再按需启用；新群默认关闭。全局启用范围仍需为「全部启用」。启用后会保存有上限、带过期时间的公开群话题，并补录发言者真实 ID 与显示名；删除群登记会一起移除这些群资料。人或 bot、是否允许互动都由主人标注。

配置她在群里的称呼后，允许互动的登记 bot 叫到她，才会进入短聊。短聊与巡检共享主动消息开关、每日群配额、最小间隔和深夜免打扰；同时限制轮数、冷却和重复消息。默认的主动间隔可能使短聊不会立即接下一轮。页面可查看没回的原因，预览只计算素材与短聊资格，不发送真实消息。群素材不取私聊日记、恋爱本或给主人留言。

### 语音收听与回复

优先使用 AstrBot 已有的语音转写；未启用宿主转写时，可通过 `voice.listen_fallback` 使用宿主配置的识别提供方兜底。成功转写会进入当前模型请求及日程、日记续聊的检索上下文。主动 TTS 设置包含分段上限、单段超时与整轮预算；失败保留原文字。被动回复的 TTS 仍由宿主管理。

语音能力卡位于 **设置**。标准 TTS 接口只接收文本，音色与语速由提供方配置，插件不宣称支持情绪音色参数。发送文件复制到 AstrBot 临时目录下的插件专属子目录，以符合宿主的文件发送白名单；至少保留 10 分钟，默认 6 小时后可清理，提供方返回的原文件不删除。宿主文件服务可用时交接限时 URL，实际 QQ 播放、手机依赖及模型画面仍待实机验收。

### 桌宠状态同步（第一阶段）

手机 AstrBot 保存角色的日程和情绪，Windows 桌宠可独立显示当前活动、下一项、心情与最后同步时间。这个阶段只同步状态，聊天仍走桌宠现有后端，不表示已经共享完整对话历史或记忆。

在已登录面板 **设置 → 生活 → 桌宠状态同步** 配置监听 IP、端口和角色 ID，再开启。默认关闭，`127.0.0.1` 仅本机；电脑连接手机时，需显式绑定手机局域网 IP 或 `0.0.0.0`，缺省端口 `6196`。不要把这个端口直接暴露到公网；跨不可信网络使用受保护的 HTTPS 反向代理或隧道。插件不会改防火墙或宿主管理鉴权。

在同页 **桌宠设备** 卡选择已配置的主人，签发设备凭据。将本次显示的 `device_id`、`agent_id`、凭据填入桌宠启动器的独立“手机状态同步”区，服务地址填手机实际地址，例如 `http://192.168.3.23:6196`。这是专用设备凭据，不能填 Dashboard 管理 token。凭据只显示一次，手动刷新设备列表或离开页面会隐藏；需要时撤销原设备再重新签发。更换角色 ID 或移除主人后原绑定失效。设备授权台账独立保存在数据目录的 `pet-devices.json`，不进入面板常规日记导出；恢复到新机器后重新配对。

同步使用单个在途请求，默认约 15 秒刷新；活动切换、情绪过期和快照过期分别处理。网络断开保留带离线标记的进程内快照，鉴权失败立即清除；不会把“时段已过”说成“已完成”。没有设备连接时不为桌宠调用任何模型。运行依赖新增 `aiohttp>=3.9,<4`；关闭监听不导入或启动该服务。

冻结协议与测试样例见 [contracts/pet-state-v1](contracts/pet-state-v1/README.md)。后续能力见[实施路线](ROADMAP.md)。

全部配置都在面板「设置」页里改（带默认值、范围和校验，改错会被拦下来），不用动文件：

| 分组 | 管什么 | 举例 |
| :--- | :--- | :--- |
| 基础 | 总开关、时区、启用范围、亲密名单 | 默认只在私聊工作 |
| 内容 | 日记与小本本的上限和提醒时刻、作息表、深夜窗 | 单段日记字数上限 |
| 生活 | 自动日程、公开偏好、规划模型；状态生图提供方、参数与每日上限 | 生图默认关闭 |
| 主动消息 | 巡检间隔、每日上限、最小间隔、**心情暗号开关 / 暗号字符**、早晚安识别词 | 私聊每天最多 2 条 |
| 出站 | 表情包标记清洗 | 剥掉 `&&名字&&` 这类标记 |

面板标题和首页立绘也在设置页改。
