# 🌸 情绪日记

日记和主动消息插件。让 bot 有自己的日子：写日记、记小本本、有心情和作息，也会主动找你说句话。

## 功能

- **一本日记**：想写就写，一天可以写好几段；她自己翻、自己改、自己删，但开头那行（什么时候、什么心情写的）不会变，改删前还会自动备份一份。
- **两本**：普通日记给所有人；「恋爱日记」只写给你指定的人，也只有那个人能看到。
- **小本本**：只记两类——答应过的事（可以带期限）、对方说过的重要的事。日常闲聊、情绪、玩笑不记。
- **心情和作息**：心情由她自己说，系统不猜；作息表配好后，她知道自己这个点"刚醒"还是"该睡了"。
- **熟悉度**：按互动慢慢涨，太久不聊会慢慢降。只是给她自己参考的档位词，不会拿数字打扰你。
- **主动消息**：早上问好、晚上道晚安、提醒你答应过的事、你很久没来、她心情实在不好……各有各的时机和频率上限。
- **观察面板**：总览 / 日记 / 小本本 / 熟悉度 / 曲线与主动 / 数据 / 设置，七个页面。日记页可以**改、删**，删掉的段落进**回收站**、能一键还原。
- **心情暗号**：她实在撑不住的时候，会发一个字符给你（默认「。」）。只发这一个字，不带任何解释。

**数据都是能直接打开的文件**——日记就是两个纯文本，用记事本就能看，不锁在数据库里。

## 安装

需要 AstrBot **4.24.2 及以上**，更旧的版本装不上（宿主会拒绝加载）。

- **从仓库安装**：管理面板「插件管理」里填仓库地址 `https://github.com/xiaoxi2760/astrbot_plugin_denia_diary`；
- **手动安装**：把 `astrbot_plugin_denia_diary` 整个目录放进 AstrBot 的 `data/plugins/`，在「插件管理」里启用。

目前只在 QQ（NapCat / aiocqhttp）真机验证过；其余平台没测过，不打包票。

## 使用

装好后到 **Dashboard → 插件管理 → 情绪日记 → 插件页** 打开面板就行，配置都在面板里改，不用动文件。

两个指令：**/看日记**（别名 /日记卡）把一天写成一张日记卡片发到聊天里，`/日记款式`（别名 /日记卡样式）换卡片款式。

`/看日记` 是今天，`/看日记 10-06` 是那天，`/看日记 2026-10-06` 也行。卡片款式在面板「设置 → 内容 → 日记卡款式」里下拉选（六款：**纸感**（默认）/ 墨信 / 明信片 / **手帐** / 点阵本 / 火漆信笺），也可以直接在聊天里敲 **`/日记款式 手帐`** 换（中文别名认得，不用打英文）。还能在设置里**自定义卡片字体**（填字体名如 `Noto Serif SC`，或字体文件直链如 `https://…/xxx.woff2`）；渲染方式默认「精美」（经文转图服务，**日记正文会发往该服务**），可改为「朴素」（本地渲染，不出机器）或「只发文本」。

默认只在私聊工作；首页那块「这里可以放图」是封面图位，点右边的「选择文件」传一张自己的图。

日记、小本本、心情这些都是给她的工具，聊天里直接说就行：「把今天的事写进日记」「记一下，我答应你周日还书」——她自己会调。

面板里也能直接改日记：日记页每段下面有「编辑 / 删除」。删除先进回收站（上限 200 条），点「还原」会插回它原本的时间位置。

默认面板和她同一条规矩——**只能改最近 7 天的**（设置里的「可改天数」）。想在面板里改任意一段，去「设置 → 内容 → 面板不受可改天数限制」打开它；这只放宽面板，她在聊天里仍然守 7 天。

改日记只改正文，**开头那行日期和心情永远不动**（那是历史）。改之前原文会自动备份到 `diary-trash/`。

## 配置

全部配置都在面板「设置」页里改（带默认值、范围和校验，改错会被拦下来），不用动文件：

| 分组 | 管什么 | 举例 |
| :--- | :--- | :--- |
| 基础 | 总开关、时区、启用范围、亲密名单 | 默认只在私聊工作 |
| 内容 | 日记与小本本的上限和提醒时刻、作息表、深夜窗 | 单段日记字数上限 |
| 主动消息 | 巡检间隔、每日上限、最小间隔、暗号字符 | 私聊每天最多 2 条 |
| 出站 | 表情包标记清洗 | 剥掉 `&&名字&&` 这类标记 |

面板标题和首页立绘也在设置页改。
